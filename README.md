# TEMPEKU

Aplikasi berbasis web untuk informasi dan resep seputar tempe.

## Autentikasi (Rahasia)
Untuk login sebagai administrator, silakan akses rute berikut secara langsung dari browser Anda:
`/TEMPEKU/index.php?page=login-admin`

**Kredensial Default:**
- **Username:** `admin`
- **Password:** `rahasia123`


**Cara Setting Database**
- $db_host = 'localhost';
- $db_user = 'root';
- $db_pass = ''; // <-- PERHATIKAN INI
- $db_name = 'tempeku';


Harap simpan informasi ini dengan aman dan tidak menyebarkannya.
